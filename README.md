# Map Search

A tiny Chrome/Brave extension: highlight an address on any page, right-click, and choose **Search Google Maps for "…"**. Google Maps opens in a new tab next to the current one.

Multi-line selections are collapsed to a single line before searching.

## Install

1. Open `brave://extensions` (or `chrome://extensions`).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and pick this folder.

## Permissions

Only `contextMenus`. The extension can't read pages; it only receives the text you right-click.
